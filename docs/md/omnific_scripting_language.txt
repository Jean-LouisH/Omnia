# Omnific Scripting Language


## Primitive Data Types


This language has strong typing with the following primitive data types:

### Void placeholder
`void`

### Booleans
`boolean` / `bool`

### Natural numbers / Unsigned integers
`natural8` / `nat8` / `uint8`, `natural16` / `nat16` / `uint16`, `natural32` / `natural` / `nat` / `uint32` / `uint`, `natural64` / `nat64` / `uint64`

### Signed Integers
`integer8` / `int8 `, `integer16` / `int16`, `integer32` / `int32` / `int`, `integer64` / `int64`

### Characters
`ascii` / `char`, `utf8`, `utf16`

### Floating Point
`float32` / `float`, `float64` / `double`

## Procedures

```cpp
integer example():
	boolean test_boolean = false
	natural test_natural_number = 3
	integer test_integer = -40
	ascii test_ascii_letter = 'Q'
	utf8 test_utf8 = '€'
	utf16 test_utf16 = '😏'
	float32 test_real_value = 3.14159f
    return test_integer
```

## Control Structures

```
if a > maximum:

elseif a < minimum:
    minimum = a
else:
    other = a
```

```
for item in items:
    total += item
```

## Pointers and Arrays

A pointer is represented with `*` on the declared type only. The address of a variable with `&`.

```cpp
integer value = 2
integer* value_pointer = &value
```

Pointers can be dereferenced by:

```cpp
*value_pointer = 5
```

Collections:

```cpp
void collections_example():
	static_array<integer, 15> fixed_numbers
	fixed_numbers[0] = 4
	integer a = fixed_numbers[0] + fixed_numbers[14]

	dynamic_array<integer> variable_numbers
	variable_numbers.reserve(2)
	variable_numbers = [25, 10]
	variable_numbers.add(88)

	string<ascii> text = "This is a sentence stored in a string. 'string text' automatically defaults to 'string<ascii> text'"

	linked_list<string> string_list = {"node1", "node2"}

	stack<string> string_stack = {"bottom", "middle", "top"}

	queue<string> string_queue = {"back", "middle", "front"}
	string_queue.push("new_front")
	string_queue.pop()

	dictionary<string, integer> number_registry = {{"age", 91}, {"GDP per capita", 70000}}

```

## Memory Management

`allocate()`, `deallocate()`

```cpp
void example():
	MyClass* object = MyClass.allocate()
	static_array<natural, 5>* array = static_array<natural, 5>.allocate()
	object.deallocate()
	array.deallocate()
```


Data Structure

```
structure RigidBody
    natural64 id
	static_array<ascii, 10> name
	float32 mass
	float32 x_position
	float32 y_position
```

```
void example()
	RigidBody ball
	ball.id = 32
	ball.name = "ball"
	ball.mass = 6.088
	ball.x_position = 5.01
	ball.y_position = 1.56
```
